# Foodie App
React Native / Expo final project recipe application.

## Features
- Horizontal recipe categories (10+)
- Recipe details with ingredients, instructions, prep time, servings, calories and difficulty
- Category filtering
- Favorite toggle and Favorites section
- My Food / My Recipes
- Add recipe with image picker, ingredients and steps
- Edit and delete personal recipes
- Persistent favorites and personal recipes with AsyncStorage
- Functional back navigation

## Run
```bash
npm install
npx expo start
```

The project is designed for Expo Go and Expo Snack-compatible React Native APIs.
